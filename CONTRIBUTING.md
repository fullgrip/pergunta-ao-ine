# Contribuir

Obrigado por ajudar a tornar estatísticas públicas mais acessíveis.

1. Abre uma issue com o indicador ou melhoria propostos e um link oficial do INE.
2. Faz alterações pequenas e verificáveis. Um novo indicador deve ter metadados, categorias e uma consulta real confirmadas.
3. Não coloques valores estatísticos fictícios nas respostas da aplicação. Fixtures de teste devem indicar URL e data de recolha.
4. Executa `npm test`, `npm run lint` e `npm run build` antes de propor alterações.
5. Explica alterações metodológicas, unidades e limites de comparabilidade no pull request.

O código é MIT. Mantém a atribuição ao INE e respeita os termos do modelo Gemma.
